# ADR 0012: listado visual de cercanos

2026-10-02. Aceptado para presentación.

Priorizar tarjetas antes del mapa, agrupadas por compatibilidad, con minutos y precio destacados, cocina y dirección. Conservar orden de ruta y filtros estrictos del servidor. Mapa desplegable secundario, manteniendo ajuste de salida y marcadores. Enlaces Google Maps por nombre y dirección para consultar reseñas sin importar datos ni inventar puntuaciones. Ratings automáticos pendientes: falta decisión del usuario sobre facturación Places frente al presupuesto cero vigente. Sin cambios de datos ni migraciones.

Usuario confirma mantener coste cero: se acepta consultar reseñas mediante enlace Google Maps, sin ratings automáticos ni facturación.
